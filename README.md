# Findter

Static Shopify-admin mockup for Findter Filter & Search.

- Open `findter-mockup/Findter.html` (redirects to `index.html`).
- Rebuild with `python3 findter-mockup/assemble.py`.
- App Home iframe loads Polaris 2.0 RC: `https://cdn.shopify.com/shopifycloud/polaris-2.0-rc.js` (see `findter-mockup/app/shell.html`).
