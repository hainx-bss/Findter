# Screens

Full-page Shopify Admin snapshots that are **not** the Findter App Home.

| Screen | Path | Use |
| --- | --- | --- |
| Theme Editor (Apps) | [`theme-editor/`](theme-editor/) | Merchant enables Findter app embed |
| Theme Editor (incompatible) | [`theme-editor/?themeIssue=1`](theme-editor/index.html?themeIssue=1) | Same screen; Compatibility modal shows when embed is on |

Open from the Findter mockup overflow menu (**Mockup cases**), or from **Enable App In Theme Editor** in the theme flow.
